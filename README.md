Bengaluru Metro Route Finder

Project Overview

The Bengaluru Metro Route Finder is a Java-based application that helps users find routes between metro stations on the Purple, Green, and Yellow lines of Namma Metro.

Objectives

- Find a route between a source and destination station.
- Display the complete route and station sequence.
- Identify interchanges between metro lines.
- Estimate journey distance, travel time, and fare.

Technologies Used

- Java
- Object-Oriented Programming
- HashMap and LinkedList
- Graph representation
- Breadth-First Search (BFS)
- Java Collections Framework

Features

- Accepts source and destination station names.
- Supports multiple station-name variations.
- Finds routes using graph traversal.
- Displays interchange information and metro direction.
- Estimates distance, journey time, and fare.
- Handles invalid or unsupported station names.

Metro Lines Included

- Purple Line
- Green Line
- Yellow Line

How to Run

1. Install the Java Development Kit (JDK).

2. Save the source code as "Main.java".

3. Open a terminal in the folder containing the file.

4. Compile the program:
   
   "javac Main.java"

5. Run the program:
   
   "java Main"

6. Enter the source station and destination station when prompted.

Note

The station connections, distance, travel time, and fare are simplified project estimates. They may differ from actual Namma Metro routes, schedules, and ticket prices.
